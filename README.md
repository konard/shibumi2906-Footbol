# Football Game

2D футбольная игра на Python с использованием pygame-ce с улучшенным ИИ и системой уровней сложности.

## Требования

- Python 3.12 или выше
- pygame-ce

## Установка

### Быстрая установка

1. **Автоматическая установка (рекомендуется):**
   - Дважды кликните на `ЗАПУСТИТЬ_ИГРУ.bat` — он автоматически создаст виртуальное окружение, установит зависимости и запустит игру
   - Или запустите `СОЗДАТЬ_ОКРУЖЕНИЕ_И_УСТАНОВИТЬ.bat` для создания окружения

2. **Ручная установка:**
```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate.bat

# Установка зависимостей
pip install -r requirements.txt
```

## Запуск

### Простой способ:
- Дважды кликните на `ЗАПУСТИТЬ_ИГРУ.bat`

### Через командную строку:
```bash
python main.py
```

## Управление

### В меню:
- **1** - выбрать легкий уровень ИИ (бот играет только на своей половине)
- **2** - выбрать сложный уровень ИИ (бот играет по всему полю)
- **ENTER** - начать игру

### Во время игры:
- **WASD** или **Стрелки** - движение игрока
- **SPACE** - удар по мячу (когда мяч в зоне действия)
- **ESC** - пауза/выход из игры

### После окончания игры:
- **R** - перезапустить игру
- **ESC** - выйти из игры

## Особенности

### Игровая механика:
- **Физика столкновений** с использованием `pygame.Vector2`
- **Реалистичная физика мяча** с трением и ограничением скорости
- **Система ударов** с зоной действия и силой удара
- **Отскок от стен** с потерей энергии
- **Система голов и счета**
- **Таймер игры** (90 секунд)

### Искусственный интеллект:
- **Машина состояний (FSM)** с тремя состояниями:
  - **ATTACK** - атака, когда мяч на стороне ИИ
  - **DEFENSE** - защита, когда мяч на стороне игрока
  - **RETREAT** - отступ, когда мяч за спиной ИИ
- **Два уровня сложности:**
  - **Легкий (1)** - бот играет только на своей половине поля
  - **Сложный (2)** - бот играет по всему полю, активнее атакует
- **Защита от автоголов** - бот не забивает себе
- **Активный отбор мяча** в режиме защиты
- **Правильное определение своих и чужих ворот**

### Системы:
- **Логирование** - все события записываются в папку `logs/`
- **Обработка ошибок** - информативные сообщения с деталями
- **Тестирование** - полный набор тестов для всех компонентов

## Уровни сложности ИИ

### Легкий уровень (клавиша 1):
- Бот играет только на своей половине поля
- Не переходит за центр поля
- Ближе к своим воротам в защите
- Подходит для новичков

### Сложный уровень (клавиша 2):
- Бот играет по всему полю
- Может переходить на половину противника
- Активнее атакует и преследует мяч
- Атакует, если мяч близко к воротам противника
- Для опытных игроков

## Настройки

Все настройки игры можно изменить в файле `settings.py`:
- **Размеры окна** - `SCREEN_WIDTH`, `SCREEN_HEIGHT`
- **Скорости** - `PLAYER_MAX_SPEED`, `BALL_MAX_SPEED`
- **Физика** - `FRICTION`, `BOUNCE_DAMPING`, `PLAYER_ACCEL`
- **Удары** - `KICK_POWER`, `KICK_RADIUS`
- **Игровые параметры** - `GAME_DURATION`, `GOAL_CELEBRATION_TIME`
- **Уровни сложности** - `AI_DIFFICULTY_EASY`, `AI_DIFFICULTY_HARD`

## Решение проблем

### Игра не запускается
1. Проверьте, установлен ли Python 3.12+
2. Убедитесь, что pygame-ce установлен: `pip install pygame-ce`
3. Проверьте логи в папке `logs/`

### Ошибки при запуске
- Все ошибки логируются в папку `logs/`
- Проверьте файл `game_output.txt` (если использовали `RUN_AND_LOG.bat`)
- Убедитесь, что все зависимости установлены

### Проблемы с виртуальным окружением
- Используйте `СОЗДАТЬ_ОКРУЖЕНИЕ_И_УСТАНОВИТЬ.bat`
- Или создайте вручную: `python -m venv venv`
